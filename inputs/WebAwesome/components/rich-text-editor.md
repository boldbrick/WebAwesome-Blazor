Writers choose styles that describe what text is, not how it looks. There are no font or size controls, so content takes on the typography of wherever it's displayed. The color and alignment tools aren't in the default toolbar, but can be added when you need them.

```html
<wa-rich-text-editor label="Description" placeholder="Describe the project"></wa-rich-text-editor>
```

```html
<wa-rich-text-editor label="Release Notes" hint="Summarize what changed in this version.">
  <p>Exports now include <strong>custom fields</strong> and respect the active filters.</p>
</wa-rich-text-editor>
```

This component works with standard `<form>` elements. See [form controls](https://webawesome.com/docs/form-controls) for form submission and client-side validation.

## Examples

### Label

Use the `label` attribute to give the editor an accessible label. For labels that contain HTML, use the `label` slot instead.

```html
<wa-rich-text-editor label="Comment"></wa-rich-text-editor>
```

### Hint

Add a descriptive hint to an editor with the `hint` attribute. For hints that contain HTML, use the `hint` slot instead.

```html
<wa-rich-text-editor label="Bio" hint="A few sentences about your background and interests."></wa-rich-text-editor>
```

### Placeholder

Use the `placeholder` attribute to add a placeholder. It shows when the editor is empty.

```html
<wa-rich-text-editor label="Reply" placeholder="Write a reply"></wa-rich-text-editor>
```

### Initial Value

Like a `<textarea>`, the editor reads its initial value from the HTML between its tags. Resetting the containing form will restore it. To write the initial value in Markdown instead, set the [`format` attribute](#markdown) to `markdown`.

```html
<wa-rich-text-editor label="Meeting Notes">
  <h2>Decisions</h2>
  <ul>
    <li>Ship the import tool in the next release.</li>
    <li>Move the weekly check-in to <strong>Thursdays</strong>.</li>
  </ul>
  <p>Next review is scheduled for <em>the end of the month</em>.</p>
</wa-rich-text-editor>
```

You can also use the `value` attribute with escaped HTML, or set the `value` property. When the `value` attribute is present, content between the tags is ignored.

```html
<wa-rich-text-editor
  label="Product Summary"
  value="&lt;p&gt;Lightweight, water-resistant, and built for &lt;strong&gt;everyday carry&lt;/strong&gt;.&lt;/p&gt;"
></wa-rich-text-editor>
```

**Only place trusted markup between the tags.**  
The browser runs any scripts in it before the editor reads it. For content users wrote, use the `value` attribute or property instead.

The value is serialized from the editor's content, so it can differ from the markup you set. Unsupported markup is dropped, headings outside [`heading-levels`](#heading-levels) move to the nearest allowed level, and [disabled features](#disabling-features) are removed. For the full list of what the value keeps, see [Displaying the Content](#displaying-the-content).

It exposes the required, readonly, disabled, and invalid states. Always give the editor a label with the <code>label</code> attribute or slot.</p> <p>The toolbar is a single tab stop. Use the arrow keys to move between tools, including those in the <code>actions</code> slot, and <kbd>Home</kbd> and <kbd>End</kbd> to jump to the first and last. Toggle buttons report whether their format is active.</p> <p>Tooltips show each tool's name and shortcut, and <kbd>Escape</kbd> dismisses them. They're visual only, since each tool has its own accessible name. Give icon-only custom buttons a name with the <code>label</code> attribute on their <a class="component-ref" href="/docs/components/icon"><code>&lt;wa-icon&gt;</code></a>.</p> <p>In lists and tables, <kbd>Tab</kbd> indents list items and moves between cells. Elsewhere, it moves focus out of the editor as usual.</p> <p>Menus and editors opened from the toolbar take focus and return it to the content when they close. <kbd>Escape</kbd> closes them without changes. Screen readers announce swatches by their <code>label</code>, so make sure custom swatches have one. The table size picker works with the arrow keys and announces its size.</p> <p>The editor announces changes that aren't otherwise visible, such as a removed link, an inserted table, available suggestions, and the remaining character count. While suggestions are open, focus stays in the content and the highlighted one is conveyed with <code>aria-activedescendant</code>.</p> <p>The image editor asks for alt text, and the embed editor asks for a title, which names the <code>&lt;iframe&gt;</code>. Encourage users to fill them in. An <code>imageProvider</code> skips the image editor, so resolve with <code>alt</code> text when you have it. Users can still click the image to add it.</p> <h2 id="api" class="anchor-heading">API </h2> <h3 id="importing" class="anchor-heading">Importing </h3> <p> If you're using the autoloader or a hosted project, components load on demand &mdash; no manual import needed.
