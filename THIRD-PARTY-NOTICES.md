## Web Awesome documentation

Packages that a local Release build makes include a documentation bundle under `docs/`. In the `WebAwesome.Blazor` package, the folder `docs/content/web-awesome/` contains the documentation of [Web Awesome](https://github.com/shoelace-style/webawesome) for the bound Web Awesome version. The source is the `packages/webawesome/docs/docs` folder of the Web Awesome repository at the tag of that version. Some component pages come from the reference docs in the Web Awesome release. A comment at the top of each such page names its source.

The packages from nuget.org do not contain this bundle.
